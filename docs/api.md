# API conventions

## Surface

All application endpoints are under `/api/v1`. OpenAPI is generated by FastAPI and is a contract artifact; breaking changes require a new API version or an explicit migration window.

Milestone 0 exposes only:

- `GET /api/v1/health`: process liveness and non-secret build/environment metadata.
- `GET /api/v1/ready`: PostgreSQL connectivity; returns a safe HTTP 503 envelope when unavailable.

Later milestones add `/auth`, `/accounts`, `/transactions`, `/transfers`, `/reallocations`, `/reconciliations`, `/debts`, `/people`, `/merchants`, `/products`, `/categories`, `/tags`, `/analytics`, `/media`, `/recurring`, and `/goals` in roadmap order.

## Money representation

```json
{
  "amount": "100.0000",
  "currency": "MAD"
}
```

JSON numbers are not accepted for money. This prevents clients from introducing binary floating-point values before validation.

## Errors

All expected errors use one envelope:

```json
{
  "error": {
    "code": "NEGATIVE_BALANCE_NOT_ALLOWED",
    "message": "The operation would take the account below its allowed balance.",
    "details": {"account_id": "..."},
    "request_id": "..."
  }
}
```

Messages are safe for users. `details` contains structured, non-sensitive repair hints. Unknown failures return `INTERNAL_ERROR` without stack traces or private data.
Framework 404/405 responses, request validation failures, domain errors, and
readiness failures use the same envelope. Every response includes `X-Request-ID`;
a valid caller-supplied request ID is echoed, while an invalid one is replaced.

## Idempotency

Balance-affecting POST endpoints require:

- `Idempotency-Key`: UUID generated once for the business operation.
- `client_operation_id`: the same stable UUID in the request body.
- Canonical request hashing on the server.

Retries with the same key and body return the original status/body. Reuse with a different body returns HTTP 409 and `IDEMPOTENCY_CONFLICT`.

The Milestone 0 coordinator and PostgreSQL constraints implement this behavior and
commit the business effect, audit event, and stored response atomically. No
balance-affecting HTTP endpoint is exposed until its milestone implements the
corresponding authenticated use case.

## Optimistic concurrency

Metadata updates carry `version`. Stale versions return HTTP 409 `VERSION_CONFLICT`.

Preview/commit workflows return a short-lived preview token bound to authenticated user, request values, and relevant account versions/balances. A stale token returns `STALE_BALANCE`; the client must refresh and ask the user to confirm again.

## Pagination and time

- Collections use cursor pagination with deterministic `(occurred_at, id)` ordering where time matters.
- Timestamps are RFC 3339 UTC strings.
- Date grouping accepts an IANA timezone and defaults to the authenticated user's configured timezone.
